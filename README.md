# Redmine Time Tracker

Расширение Chrome для учёта времени в Redmine.

## Сборка и установка

Требуется Node.js 18 или новее.

```sh
npm install
npm run build
```

В Chrome откройте `chrome://extensions`, включите режим разработчика и выберите «Загрузить распакованное расширение», указав папку `dist`. После изменения исходного кода повторите сборку и обновите расширение на странице `chrome://extensions`.

При первом запуске укажите адрес Redmine и API-ключ. Настройки сохраняются в `chrome.storage.sync`.
